Python Practice – Learning Python Through W3Schools Modules
Dette prosjektet er et personlig øvingsmiljø for å lære Python steg for steg. Strukturen følger modulene i W3Schools Python Tutorial, og hver mappe/fil inneholder små, fokuserte eksempler som bygger opp forståelse av grunnleggende og videregående konsepter.

Målet er å lære Python gjennom praktisk koding, korte eksempler og repeterbare øvelser
